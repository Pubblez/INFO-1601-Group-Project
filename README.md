# INFO 1601 Group Project

This is a group coursework project for the INFO 1601 course.  
It is a multi-page web application built using HTML, CSS, and JavaScript.

---

## 🌐 Live Demo
https://blush-jor6.onrender.com/

---

## Project Context

This project was originally developed collaboratively in a Replit workspace as part of the INFO 1601 coursework. It was later exported and uploaded to GitHub for version control and archival purposes.

Because Git was not used during the initial development phase, only a single contributor appears in this repository.

---

## Pages / Structure

This is a multi-page static website consisting of the following pages:

- `index.html` – Home page  
- `aboutus.html` – About the project/team  
- `products.html` – Product or feature listing page  
- `routine.html` – Routine-related page  
- `navbar.html` – Navigation component

2. Open the folder  
3. Open `index.html` in any web browser  

No installation or setup required.
